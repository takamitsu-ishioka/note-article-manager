# 新テーマ：防衛の主体は国家である必要があるか？

これは、国家という制度の根本に踏み込む問いですね。

通常、防衛については次のような前提が置かれています。

> 国家が国民を守る。したがって、国家は軍隊を保有し、防衛政策を決定しなければならない。

しかし、この論理には飛躍があります。

**「防衛が必要である」という命題から、「防衛の主体は国家でなければならない」という命題は導けません。**

ここを分解してみましょう。

## 1\. そもそも何を守るのか？

防衛の対象には、少なくとも四つあります。

1. **生命・身体**：個々の人間の安全
2. **財産・生活基盤**：住宅、企業、インフラなど
3. **社会秩序**：取引、交通、通信、法的関係など
4. **国家主権**：領土、国境、統治機構など

この四つは同じではありません。

たとえば、国家主権を維持するための戦争が、国民の生命や財産を大量に破壊することもあります。

逆に、国家の統治機構が崩壊しても、人々の生活や経済活動がすべて消滅するとは限りません。

つまり、

**国家を守ることと、人間を守ることは、必ずしも一致しない。**

ここが出発点になります。

## 2\. 防衛という仕事を分解する

防衛を一つの巨大な仕事として扱うから、巨大な国家組織が必要に見えるのかもしれません。

しかし、機能ごとに分解すると様子が変わります。

| 機能 | 考えられる主体 |
|--------|--------|
| 脅威の監視・検知 | 企業、研究機関、住民組織 |
| 防護設備の整備 | 企業、自治体、個人 |
| 避難・救助 | 地域組織、民間事業者、自治体 |
| サイバー防御 | 各システムの運営主体 |
| 物資・輸送の確保 | 物流企業、地域ネットワーク |
| 武力による侵攻阻止 | 国家軍、共同防衛組織など |
| 停戦・和平交渉 | 国家、国際機関、交渉当事者 |

これを見ると、国家だけが担えると最初から断定できる機能は、実はそれほど明白ではありません。

ただし、武力行使の正統性、指揮命令、費用負担、国際法上の責任については、民間主体に分解するだけでは解決しない問題が残ります。

## 3\. すでに防衛の一部は国家の外にある

民間軍事・警備会社は、施設警護、軍事訓練、装備の保守などを担っています。赤十字国際委員会（ICRC）も、こうした活動を国際人道法の対象として扱っています。\[[International humanitarian law and private military/security companies - FAQ](https://www.icrc.org/en/document/ihl-and-private-military-security-companies-faq?utm_source=chatgpt.com); [Private military and security companies](https://www.icrc.org/en/law-and-policy/private-military-and-security-companies?utm_source=chatgpt.com)\]

一方、現行の国際秩序では、国連憲章第51条が国家の個別的・集団的自衛権を規定しています。民間企業に業務を委託しても、国家の国際法上の義務は消えません。\[[国連憲章テキスト](https://www.unic.or.jp/info/un/charter/text_japanese/?utm_source=chatgpt.com); [The Montreux document](https://www.icrc.org/sites/default/files/external/doc/en/assets/files/other/icrc_002_0996.pdf?utm_source=chatgpt.com)\]

つまり、**防衛の実行主体と、防衛の法的責任主体は、すでに部分的に分離している**わけです。

## 4\. さらに根本的な問題

ここで一つ、思考実験をしてみます。

ある地域に100万人が住んでいるとします。

彼らはそれぞれ、財産を持ち、商売をし、他者と契約しています。

外部から武装集団が侵入してきた場合、住民たちは共同で防衛サービスを購入することにしました。

さて、この共同購入組織は国家でしょうか？

国家でないなら、何が欠けているのでしょうか？

逆に、これが国家なら、**防衛サービスの共同購入と国家の成立は、どこで区別されるのでしょうか？**

そして、最大の問題が残ります。

共同購入に参加しない住民も守られてしまうという、公共財としての防衛の性質です。費用を誰が負担するのか。参加しない自由を認めるのか。武力行使の判断を誰が下すのか。

ここを解かずに民営化だけを進めれば、国家の代わりに私的な武力独占組織が生まれる可能性もあります。
