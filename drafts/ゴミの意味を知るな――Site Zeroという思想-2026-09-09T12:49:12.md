ゴミの意味を知るな――Site Zeroという思想

## ビジョン――ゴミ処理を、人間の仕事から物理の仕事へ

未来のゴミ箱は、一つでいい。

人間は、不要になった物をそこへ入れる。

その先で機械が、

- 磁性
- 電気伝導性
- 密度
- 大きさ
- 形状
- 光学特性
- 赤外線スペクトル

などを観測し、物質を分離する。

鉄は鉄へ。  
アルミはアルミへ。  
PETはPETへ。  
PPはPPへ。

そして再び、それぞれが新しい製品の材料になる。

ここで重要なのは、機械が**「その物が何だったのか」を知る必要がない**ことである。

フライパンだったのか。

シャンプーの容器だったのか。

食品トレーだったのか。

玩具だったのか。

そんなことは、物質循環にとって本質ではない。

製品としての役割を終えた瞬間、その物体から人間が与えた「意味」を剥がす。

そして物理へ戻す。

**製品 → 物質 → 製品**

物質循環のボトルネックを、人間による「ゴミの意味の解釈」から、機械による「物性の観測」へ移す。

これが本稿で描くビジョンである。


# 1. 「不燃ごみ」とは何なのか

話の始まりは、極めて素朴な疑問だった。

**不燃ごみには、リサイクルできる物質が大量に含まれているのではないか。**

たとえば鉄である。

鍋、工具、金属製品、家電の部品。

それらが他のゴミと混ざっていても、鉄には非常に都合のいい性質がある。

**磁石にくっつく。**

ならば、人間が一個ずつ、

「これは鉄製の鍋です」

と判断する必要はない。

破砕してコンベアに流し、磁石を置けばいい。

機械はそれが鍋だったことを知らない。

知る必要もない。

> **鉄だから回収する。**

ただそれだけである。


# 2. アルミは磁石につかない。ではどうする？

鉄だけなら話は簡単だ。

しかしアルミニウムは磁石にはほとんどつかない。

では、人間がアルミ缶やアルミ製品を見つけて拾わなければならないのか。

そうではない。

**渦電流選別**という方法がある。

高速で変化する磁場の中にアルミなどの導体を通すと、内部に渦電流が生じる。その電流が作る磁場によって力を受けるため、コンベアの先で非鉄金属だけ違う軌道へ飛ばすことができる。

つまり、

**鉄 → 磁性**

**アルミなど → 電気伝導性**

と、異なる物理特性を使って分離できる。

ここでも、

「これはアルミ缶である」

という意味判断は必要ない。

機械に必要なのは、

「電気をよく通す物体がここにある」

という観測だけである。


# 3. 重いか、軽いか

もっと原始的な物理も使える。

**重力である。**

金属、ガラス、石、プラスチック、紙。

これらは密度が違う。

さらに風を当てれば、軽いフィルムや紙片と、重いガラスや金属片では運動が変わる。

水や特定の液体を使えば、浮く物と沈む物にも分けられる。

つまり、

**密度**

**重量**

**空気抵抗**

というだけでも選別ができる。

ゴミ処理施設から見れば、

> お前が何者だったかには興味がない。  
> 風を当てたとき、どう飛ぶかを見せろ。

である。


# 4. 大きさも情報である

さらに単純なのが**ふるい**である。

破砕物を回転する筒状のスクリーンなどに通せば、小さいものは穴から落ち、大きいものは先へ進む。

これも認識ではない。

判断ですらない。

単に、

**直径50mmの穴を通れるか。**

という物理現象である。

ここまで来ると、ゴミ処理施設が巨大なプログラムに見えてくる。

入力された混合物に対して、

磁性があるならAへ。

導電性が高ければBへ。

小さければCへ。

軽ければDへ。

重ければEへ。

という処理を繰り返しているだけである。


# 5. 光を当てれば、プラスチックまで分かる

難しいのはプラスチックである。

PET、PE、PP、PS、PVC。

見た目だけでは区別しにくい。

ところが物質は、光に対してそれぞれ異なる振る舞いをする。

そこで使われるのが**近赤外線（NIR）選別**である。

近赤外線を照射し、その反射スペクトルを測れば、樹脂の種類を高速に識別できる。

そして対象物がコンベア上の所定位置まで来た瞬間に、圧縮空気などで別のラインへ飛ばす。

ここで初めて高度な「認識」に近づいてくる。

しかし認識しているのは、

**「これは洗剤のボトルである」**

ではない。

**「この物質のスペクトルはHDPEに対応する」**

である。

製品の意味ではなく、物質の性質を見ている。


# 6. そしてSite Zeroへ

この思想を巨大な工業設備として実装している例がある。

スウェーデンのモータラにある、Svensk Plaståtervinningの**Site Zero**である。

Site Zeroは家庭から回収されたプラスチック包装を受け入れる大規模選別施設で、年間受入能力は20万トン。

毎時42トン。

毎秒約1,000個の包装を処理する。

選別ラインの総延長は5.5km。

そして施設には60台以上の近赤外線センサーに加えて、レーザー、カメラ、AIを利用したシステムが配置されている。工程は自動化され、リアルタイムで最適化される。

その結果、

- HDPE
- LDPE
- PP
- 透明PETボトル
- 色付きPETボトル
- 透明PETトレー
- PP系フレキシブル材
- PS
- EPS
- PVC
- 混合ポリオレフィン類

など、合計12種類のプラスチック系統へ選別できる。運営会社によれば選別効率は最大95％、選別後のベールの純度は90～98％に達する。

2025年には37,819トンの家庭由来プラスチック包装が実際にリサイクルされた。

もちろん、Site Zeroも魔法ではない。

何を投入しても100％資源になるわけではないし、そもそもSite Zeroは「何でも入れられる万能ゴミ箱」ではなく、**プラスチック包装を対象としたシステム**である。

実際、運営会社自身が、誤って混入したバッテリーは火災や操業停止の原因になると警告している。

だから現在地と究極のビジョンは区別しなければならない。

しかし、その方向は極めて興味深い。


# 7. 混合廃棄物でも同じことが始まっている

プラスチックだけではない。

フィンランドのRemeoがヴァンターで運営する施設では、建設系を中心とした廃棄物に対して、ドラムスクリーンによる粒径選別、磁石による金属分離、赤外線を利用した光学選別、さらにAI制御のロボットによる選別を組み合わせている。

ロボットは木材、金属、石、プラスチックなどを形状や組成から認識して取り除く。

ここまで来ると、選別原理の階層が見えてくる。

**磁性で分かるなら磁石を使う。**

**粒径で分かるならふるいを使う。**

**密度で分かるなら重力を使う。**

**スペクトルで分かるなら光を使う。**

**それでも分からなければAIを使う。**

最初から何もかもAIに認識させる必要はない。

物理で解ける問題は、物理に解かせればいい。


# 8. 人間は、なぜゴミを分類しているのか

ここで視点を家庭へ戻そう。

われわれは日々、

「これは可燃ごみ」

「これは不燃ごみ」

「これは容器包装プラスチック」

「これは資源」

「これは小型家電」

と分類している。

つまり家庭にいる人間が、廃棄物処理システムの**前処理装置**として働いている。

もちろん、それには合理的な理由がある。

家庭で分けてもらえば、後工程は楽になる。

危険物を取り除くこともできる。

汚染も防げる。

現在の技術と経済条件では、発生源での分別は非常に有効である。

しかし、それを永遠に当然の前提とする必要はない。

技術が進歩すれば、問いを逆転できる。

**人間はどこまで細かく分別すべきか。**

ではなく、

**機械ではどうしても処理できない分別は何か。**

である。

これはかなり違う。


# 9. ゴミには「意味」がある

そもそも、ゴミとは何だろう。

物理世界には「ゴミ」という物質は存在しない。

鉄がある。

アルミがある。

ガラスがある。

ポリエチレンがある。

ポリプロピレンがある。

木がある。

紙がある。

それらに人間が目的を与えると、

「鍋」

「缶」

「瓶」

「シャンプーボトル」

「机」

「新聞」

になる。

つまり**製品とは、物質に人間が意味を与えたものである。**

そして、その意味が失われた瞬間に、

「ゴミ」

になる。

壊れたフライパンの鉄原子が、突然ゴミ原子に変化するわけではない。

変わったのは物質ではない。

**人間との関係である。**

ならばリサイクルとは、

「ゴミを製品へ戻すこと」

というより、

一度その意味を剥がし、

**製品を物質へ戻すこと**

なのではないか。


# 10. Site Zeroという名前

だから私は、**Site Zero**という名前が好きだ。

単なる格好いい施設名ではない。

この名前は、物質循環の中での施設の位置を見事に表現しているように思える。

製品として生まれ、

社会で使われ、

役割を終え、

Site Zeroへ来る。

そこで、

鍋でも、

容器でも、

トレーでも、

ボトルでもなくなる。

人間が与えた意味がゼロになる。

残るのは物質である。

そして、その物質から再び新しい製品が作られる。

だからSite Zeroは終点ではない。

起点でもある。

**製品**
↓  
使用  
↓  
廃棄  
↓  
**SITE ZERO**  
↓  
物質  
↓  
製造  
↓  
**新しい製品**

言うなれば、

> **我は物質循環の終点にして起点なり。**

である。


# 11. 抽象化――意味の世界と物理の世界を分ける

ここまでをさらに抽象化してみよう。

人間は意味の世界に住んでいる。

「椅子」

「自動車」

「スマートフォン」

「食品容器」

という分類は、人間の目的から生まれる。

しかし自然界はそんな分類を知らない。

自然界にあるのは、

質量、

電荷、

磁性、

分子構造、

密度、

波長、

温度、

といった物理現象だけである。

問題が起こるのは、この二つを必要以上に結合したときだ。

「これは何であるか」

という意味論を、人間が最後まで背負う必要はない。

意味が必要な領域では意味を扱う。

物理で処理できる領域に入ったら、意味を捨てる。

**意味層と物理層の責務を分離する。**

するとシステムは単純になる。

ゴミ処理施設は、

「これは何に使われていた物ですか？」

と尋ねなくてよい。

> **ゴミの意味を知るな。物性を見ろ。**

となる。


# 12. 文明とは、自然に仕事を返してきた歴史である

これはゴミ処理だけの話ではない。

人類の技術史を眺めると、われわれは繰り返し同じことをしている。

人間が持ち上げていた物を、滑車に任せた。

人間が運んでいた物を、車輪に任せた。

人間が計算していたものを、計算機に任せた。

人間が記憶していたものを、文字やデータベースに任せた。

そして今、人間が認識していたものの一部を、センサーやAIに任せ始めている。

文明の進歩とは、人間が賢くなって何でも自分で処理する歴史ではない。

むしろ逆なのかもしれない。

**人間がやらなくてもよい仕事を発見し、それを物理世界へ返してきた歴史である。**

重力でできるなら、重力に任せる。

磁場でできるなら、磁場に任せる。

光でできるなら、光に任せる。

計算でできるなら、計算機に任せる。

認識が必要なら、最後にAIへ任せる。

そして人間は、人間にしか決められないものへ戻っていく。

何を作りたいのか。

何を残したいのか。

何を美しいと思うのか。

どんな社会に住みたいのか。

つまり**目的と価値**である。

Site Zeroのコンベアを流れるプラスチック片は、その小さな文明論を目に見える形で示しているように思える。

人間が作った「物」の意味がそこで一度消える。

物理へ還る。

そして、別の意味を与えられて再び人間社会へ戻ってくる。

**意味 → 物質 → 意味。**

われわれが「ゴミ」と呼んでいるものは、文明の終端にあるのではない。

次の意味を待っている物質なのである。
