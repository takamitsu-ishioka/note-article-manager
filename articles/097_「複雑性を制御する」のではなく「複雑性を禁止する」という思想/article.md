# 「複雑性を制御する」のではなく「複雑性を禁止する」という思想

## 〜make、GUI、並列化、そしてプラトンの呪い〜

ChatGPT：  
ありますねそれ（笑）

しかも MongoDB の MongoDB Compass って、

- Reloadすると視線誘導が飛ぶ
- ソート条件を忘れる
- 「さっき見た値」が脳内キャッシュ依存
- 10分という“短すぎて忘れる／長すぎて待てる”絶妙な時間

なので、人類のワーキングメモリ破壊装置みたいになる。

対策としては、もう「目視確認」をやめて、

```
db.collection.find().sort({ timestamp: -1 }).limit(3)
```

を固定で流すとか、

```
db.collection.find(
  {},
  { timestamp: 1 }
).sort({ timestamp: -1 }).limit(2)
```

で「最新2件の差」を見る方が圧倒的にラクです。

あるいは：

```
db.collection.countDocuments()
```

を先に見て、

- 休憩前: 1521件
- 休憩後: 1522件

なら「増えた」で確認終了。

本質的には、

> 人間は状態比較に弱い  
> だから機械に差分を出させろ

なんですよね。

これ、運用監視全般で頻発します。

- 「前回CPU何%だったっけ」
- 「ログ増えた？」
- 「このPod再起動した？」
- 「件数変わった？」
- 「昨日と同じ？」

を全部“人間の記憶”でやろうとすると地獄になる。

だから監視システムは「現在値」ではなく「変化量」を表示する方向へ進化していった。
