## 1. まず試すなら、非公開Organization

GitHub.com上に会社専用のOrganizationを作り、リポジトリをすべてPrivateにします。

```text
会社
└─ GitHub Organization
   ├─ 業務A
   ├─ 業務B
   ├─ 規程
   ├─ 会議・意思決定
   ├─ 顧客別情報
   └─ 自動化ツール
```

Teamごとに閲覧・編集権限を設定すれば、

> **インターネット上には存在するが、組織の認証された人だけが入れるGitHub**

はすぐ作れます。

思想の実証実験なら、まずこれで十分です。

## 2. 企業の閉鎖空間として使うなら、GitHub Enterprise Cloud

これに、

- SAML SSO
- Microsoft Entra IDなどのIdP連携
- Enterprise Managed Users
- IP許可リスト
- 組織横断のセキュリティポリシー

を加えます。

IP許可リストを使えば、会社やVPNの特定IPアドレスからだけ、Web UI、API、Git、SSH経由でアクセスさせることもできます。([GitHub Docs](https://docs.github.com/ja/enterprise-cloud%40latest/admin/configuring-settings/hardening-security-for-your-enterprise/restricting-network-traffic-to-your-enterprise-with-an-ip-allow-list?utm_source=chatgpt.com))

つまり、

```text
社員
  ↓ 会社アカウント＋SSO
会社VPN
  ↓ IP制限
GitHub Enterprise Cloud
```

という、かなり強い論理的閉鎖空間を作れます。Enterprise Managed Usersなら、ユーザーアカウント自体を企業側で管理できます。([GitHub Docs](https://docs.github.com/en/get-started/onboarding/getting-started-with-github-enterprise-cloud?utm_source=chatgpt.com))

これは **構築は比較的簡単** です。サーバーの保守もGitHub側です。GitHub Enterprise CloudはGitHubがホストするサービスなので、自社でインフラや更新を管理する必要がありません。([GitHub](https://github.com/enterprise?utm_source=chatgpt.com))

## 3. 物理的にも閉じるなら、GitHub Enterprise Server

GitHub Enterprise Serverを自社サーバーまたは自社管理のクラウド環境に置きます。

```text
社内ネットワーク
├─ 社員PC
├─ AIサーバー
├─ 業務API
└─ GitHub Enterprise Server
```

これはGitHubのセルフホスト版で、オンプレミスや自社クラウド上に専用インスタンスを構築できます。([GitHub Docs](https://docs.github.com/enterprise-cloud%40latest/admin/overview/about-github-for-enterprises?utm_source=chatgpt.com))

外部インターネットへの接続を大幅に制限した環境でも運用でき、GitHub ActionsもGitHub.com上のActionを禁止して、社内インスタンスに保存されたものだけに限定できます。([GitHub Docs](https://docs.github.com/en/enterprise-server%403.19/admin/managing-github-actions-for-your-enterprise/managing-access-to-actions-from-githubcom/setting-up-the-tool-cache-on-self-hosted-runners-without-internet-access?utm_source=chatgpt.com))

- サーバー構築
- バックアップ
- 更新
- セキュリティパッチ
- DNS・証明書
- 可用性
- Actions Runner
- 障害対応

を自社で引き受けます。GitHub自身も、Enterprise Serverでは管理者が更新とセキュリティパッチ適用を担当すると説明しています。([GitHub Docs](https://docs.github.com/en/enterprise-server%403.19/admin/overview/about-github-enterprise-server?utm_source=chatgpt.com))
