```python  
while True:  
    response = llm(prompt)  

    if response.is_tool_call():  
        result = run_tool(response.tool)  
        prompt += result  
    else:  
        return response  
```  

極端に言えば、エージェントはこのような制御ループに近いものです（実際にはもっと複雑ですが）。

だから、進化論の用語を借りれば、  

- **ヘーゲル** ：方向性を持つ歴史観（定向進化的なイメージ）  
- **ダーウィン** ：方向を前提としない適応進化  

という対比はできます。  

ただし、厳密に言うと注意点があります。  

生物学の **定向進化説（orthogenesis）** は、「進化には生物内部にあらかじめ定まった方向性がある」という学説です。これは現在の進化生物学では支持されていません。  

ヘーゲルは生物進化を論じているわけではなく、 **精神・歴史・概念の発展** に方向性を認めています。  

ですから、  

> **ヘーゲルは歴史哲学における「定向進化的な歴史観」を持っている**  

という言い方なら、比喩として自然です。
