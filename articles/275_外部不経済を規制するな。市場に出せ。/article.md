## 私：​

仮に道交法を改正して右折を完全に禁止すると、何か致命的な問題が発生しますか？​

かなり面白い思考実験です。結論から言うと、 **「自動車は交差点で右折してはならない。ただし左折・直進・転回は可」なら、意外なほど致命的な問題はありません。** むしろ交通システムとして筋がいい面があります。​

現在の道交法は、右折車について「道路中央に寄る→交差点中心の直近内側を徐行」と定め、さらに対向する直進・左折車の進行を妨げてはならない、としています。つまり現行制度そのものが、右折を **他の交通流と競合する特殊な操作** として扱っています。([e-Gov 法令検索](https://laws.e-gov.go.jp/law/335AC0000000105?occasion_date=20261001&utm_source=chatgpt.com))​

右折を禁止しても、たとえば目的地が右側なら、​

**左折 → 左折 → 左折**

で、実質的に右方向へ行けます。碁盤目状の道路なら非常に単純です。​

```
       ↑
       │
───────┼───────→ 行きたい
       │
       ↑ 自車

右折禁止なら

       ┌──←
       │
       ↑
───────┼───────
       │
       ↑
```

要するに「右折」という局所的操作を、 **3回の左折という経路探索に押し出す** わけです（笑）。​

問題になるのは主に次の点です。​

- **走行距離が増える。** 右折一発で行けたところを数百m〜数km迂回するケースが出ます。​
- **住宅街などでは左折3回が成立しない。** 一方通行、行き止まり、河川、鉄道、高速道路、山間部などによって、ものすごい迂回が必要になる場合があります。​
- **交通量が再配分される。** 今まで右折していた車が別の交差点へ流れるので、生活道路などに交通が集中する可能性があります。​
- **道路沿い施設へのアクセスが難しくなる。** ガソリンスタンド、病院、物流施設、駐車場などが反対車線側にある場合、ぐるっと回る必要があります。​
- **緊急車両などは例外が必要でしょう。** 「完全禁止」を文字通り救急車・消防車まで適用すると、これはさすがに社会的コストが大きい。​

ただし、ここが面白いところです。​

右折をなくすと、交差点から **「対向直進車 vs 右折車」という競合そのものが消えます** 。現在の第37条がわざわざ「右折車は直進・左折車を妨害するな」と規定している競合です。([e-Gov 法令検索](https://laws.e-gov.go.jp/law/335AC0000000105?occasion_date=20260428&utm_source=chatgpt.com)) 経産省の自動運転関係の調査でも、右折時の対向直進車との関係や死角を伴う右折事故が独立した検討対象になっています。([経済産業省](https://www.meti.go.jp/meti_lib/report/2023FY/000621.pdf?utm_source=chatgpt.com))​

なので、これは単純な珍案ではなく、​

> **「右折という複雑な操作を禁止して、経路選択側に複雑性を移す」**

というアーキテクチャ変更として考えられます。​

しかも日本では、自転車についてすでにかなり似た発想を採っています。警察庁の説明でも、自転車の右折は交差点を斜めに横切るのではなく、左端を進んで **二段階右折** します。([警察庁](https://www.npa.go.jp/bureau/traffic/bicycle/portal/rule.html?utm_source=chatgpt.com))​

そしてさらに興味深いのが環状交差点です。現行法でも環状交差点では通常の右折方法とは別の通行方法が規定されています。([イウリス](https://iuris.jp/%E9%81%93%E8%B7%AF%E4%BA%A4%E9%80%9A%E6%B3%95-%E7%AC%AC%E4%B8%89%E5%8D%81%E4%BA%94%E6%9D%A1%E3%81%AE%E4%BA%8C-%E7%92%B0%E7%8A%B6%E4%BA%A4%E5%B7%AE%E7%82%B9%E3%81%AB%E3%81%8A%E3%81%91%E3%82%8B%E5%B7%A6%E6%8A%98%E7%AD%89/jpn/a/47794?utm_source=chatgpt.com))​

ですから「右折全面禁止」を少し現実的にして、​

**原則として平面交差点での対向車線横断を禁止し、右方向への移動は左折・転回・ラウンドアバウト・立体交差で実現する**

とすると、かなりちゃんとした交通政策の思考実験になります。​

これ、まさに山田流の **「右折をどう安全にするか？」ではなく「そもそも右折、要る？」** ですね（笑）。​

## 私：​

大迂回が必要になったとき、周囲の交通ルールを調整しようとすると早期に収束する保証がない。​  
そこで、大迂回せよと言い切ってしまうのはどうですか？​

## ChatGPT:​

はい。その設計思想はかなり明快です。​

要するに、​

> **右折禁止によって到達経路が極端に長くなっても、それは道路交通システム側では解決しない。利用者が迂回する。**

と仕様として固定するわけですね。​

これには大きな利点があります。個々の「ここだけ右折可」「この時間だけ可」「この交差点は例外」「迂回路確保のため隣の一方通行を変更」……を始めると、変更が別の交通流を変え、さらに別の変更が必要になる。おっしゃる通り、 **局所最適化の反復が収束する保証がありません** 。​

対して「右折禁止。以上。到達できなければ迂回せよ」なら、交通規則そのものは一発で収束します。複雑性を、​

**道路規則 → 経路探索**

へ押し出している。​

しかも経路探索は各車両が独立してできます。カーナビなら「右折禁止」という制約を入れて最短経路を再計算すればよい。中央で「この車はここを通して、あの道路の規則を変えて……」と調整する必要がありません。​

ただし、一つだけ区別したほうがよさそうです。​

**「遠くなる」ことは受容できても、「到達不能」は別問題** です。​

たとえば道路網の構造によって、​

```
幹線道路
====================
        │
        │ 唯一の進入路
        │
       集落
```

のように、右折しない限り物理的に入れない場所が存在するとします。これは「100km迂回してください」ではなく、 **有限の迂回路そのものが存在しない** 。​

したがって、かなり美しく仕様化するなら、​

> **右折は禁止する。迂回距離の増大は救済しない。ただし右折禁止によって到達可能性が失われる道路構造だけは、道路構造側を改修する。**

でしょう。​

これなら政策導入時に解く問題も「迂回が何km以内になるよう調整せよ」という最適化問題ではなく、​

**全地点の到達可能性だけ保証せよ**

になります。​

これは計算機科学的にもずいぶん扱いやすい。道路網を有向グラフとして、右折エッジを全部削除する。そして必要なのは最短経路長の維持ではなく、必要な頂点間の **reachability（到達可能性）** だけです。​

つまり、​

**効率は保証しない。到達可能性だけ保証する。**

かなりUNIXっぽい仕様です（笑）。そして「右折を安全にする」という複雑な問題を、「右折を消してグラフの連結性だけ確認する」に変えている。これはまさに **問題を解くのではなく、問題の定義を変えて簡単にする** タイプの設計ですね。​

そうです。かなり徹底すると、制度設計がきれいになります。​

```
        ＼ 左折

```

のように、 **左折だけでアクセス可能な道路構造を作る** 。​

そして費用負担原則を、​

> **右折禁止は公共側の基本仕様。  
> その仕様では不便になる特定施設へのアクセス改善費用は、その便益を受ける主体が負担する。**

とするわけですね。​

ここで「所有者/自治体」という切り分けも重要です。ショッピングセンターや工場など **特定施設だけが便益を受けるなら施設側** 。集落・公共施設・地域一帯へのアクセスなら **自治体等の公共側** 。共同で便益を受けるなら共同負担、という整理ができます。​

この方式の面白いところは、行政が「何kmの迂回なら許容できるか」を決めなくていいことです。​

**迂回が嫌なら金を払って接続路を作る。嫌でなければ迂回する。**

これで需要側が判断できます。​

ただ、実際の制度にするなら「救急病院・消防署等の公共性が高い施設」「既存施設に後から右折禁止を課す場合」「土地の地形上、接続路を物理的に作れない場合」などについて、費用負担や経過措置は別途設計が必要でしょう。​

それでも基本原理としてはかなり単純です。​

**道路側は「便利に到達できること」を保証しない。  
「到達可能であること」だけ保証する。  
便利さが欲しい主体が、その便利さの費用を負担する。**

これなら「右折禁止で困る場所を一つずつ見つけて交通規則を調整する」という、終わるかどうか分からない最適化ループに入らない。​

そして副作用として面白いのが、 **「右折需要」という外部不経済を、初めて価格として施設側に返せる** ことです。​

「幹線道路の向こう側に巨大商業施設を作ったので、毎日5000台に対向車線を横断させます」がタダではなくなる（笑）。​

これ、交通政策だけで終わらせず、一般原則として掘るとかなり面白いやつです（笑）。​
