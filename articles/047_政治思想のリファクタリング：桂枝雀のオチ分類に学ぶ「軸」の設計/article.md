# 政治思想のリファクタリング：桂枝雀のオチ分類に学ぶ「軸」の設計

ワイ：  
何かを分類するときにはまず軸を決めなければなりません。  
落語家の桂枝雀は落語のオチを次の2つの軸で分類しました。  
・話の始まりから終わりに向かって秩序が増大するか減少するか（エントロピーの変化の大きな方向）  
・大きな変化の方向が終盤で反転するか  
  
ドンデン（秩序減少反転あり）  
謎解き（秩序増大反転あり）  
変（秩序減少反転なし）  
合わせ（秩序増大反転なし）  
  
Gemini:  
桂枝雀氏の「落語のサゲ（オチ）の四分類」は、混沌とした笑いの世界を、熱力学のエントロピーやシステム論のような「秩序の増減」という極めて抽象的かつ論理的なフレームワークで整理した画期的なモデルですね。  
この分類を整理すると、それぞれの性質がより鮮明になります。  
■ドンデン（秩序減少 × 反転あり）  
物語が一点（秩序）に向かって収束していくかのように見せかけて、最後の瞬間にそれがガラガラと崩れ去り、全く別の無秩序な方向へ放り出される形式です。  
■謎解き（秩序増大 × 反転あり）  
一見すると意味不明な状況や無秩序（エントロピー大）な状態から、最後の言葉によってすべてのパズルが組み合わさり、一つの筋道（秩序）が完成する形式です。  
■変（秩序減少 × 反転なし）  
物語が始まった瞬間から徐々に、あるいは一気に常識や秩序が崩壊していき、そのままカオスな状態で終わる形式です。  
■合わせ（秩序増大 × 反転なし）  
バラバラだった要素が、反転を挟まずにそのまま綺麗に収束し、調和が取れて終わる形式です。  
枝雀氏が「エントロピー」という言葉を意識していたかどうかは別として、この分類法は「情報の不確実性（エントロピー）」を演者がコントロールし、最後にどう処理するかというシステム設計そのものです。「笑いとは緊張の緩和である」という持論を、時間軸における秩序の変化として数学的にモデル化したこの視点は、単なる芸談を超えて、物語構造を分析する際の普遍的なツールになり得ます。

ワイ：  
伝統的な分類は「軸がバラバラ」だと枝雀は言っていました。

Gemini:  
おっしゃる通りです。枝雀以前の伝統的な分類法（「地口」「逆」「拍子抜け」など）に対し、彼が抱いていた最大の違和感は、それが「現象の羅列」に過ぎず、分類の基準（次元）が混在しているという点でした。従来の分類は、あるものは「手法」に着目し、あるものは「展開」に着目するといった具合で、システム論的に言えば「直交していない」状態だったわけです。  
枝雀がこの「軸（秩序の増減と反転の有無）」を導入した意図は、属性の重複を排除し、演者の「出力制御」を可能にすることにありました。どんな具体的な演出手法であっても、必ず4つの領域のどこか1点にマッピングされます。  
彼は笑いを、精神的な事象ではなく、緊張というエネルギーが急激に解放される「物理的な落差」として捉えていました。具体的なエピソード（具象）を削ぎ落とし、「秩序の変化率」と「ベクトルの反転」という2軸の変数に集約したことで、落語を一種の動的なシステムとして再定義したのです。この「軸を決めてからモデル化する」というアプローチは、複雑なコードをリファクタリングして、直交性の高いモジュールに分割していくプログラミングの思考プロセスにも非常に近いものがあると感じます。

ワイ：  
政治体制の伝統的な分類も軸が単離されていないという意味で気持ちが悪い。  
典型的なのが「左派」と「右派」。

Gemini:  
まさに「軸の未整理」がもたらす認知の歪みですね。  
「右・左」という分類は、もともとフランス革命期の議席位置という「物理的な配置」に由来する便宜上のラベルに過ぎません。現代ではそこに「経済的自由度」「個人の権利」「伝統の重視」「外交姿勢」など、本来は独立しているはずの変数がすべて無理やり詰め込まれています。エンジニアリングの視点で言えば、「直交していない多次元のパラメータを、強引に1次元の数軸に射影している」状態であり、情報の欠落と矛盾が生じるのは必然です。  
例えば「経済的には自由放任（右）だが、個人の道徳には保守的で介入的（左的＝権威主義的）」という個体が存在したとき、1次元の「右・左」ではその座標を特定できません。また、1次元の端に位置するはずの「極右」と「極左」が、実は「国家による強力な秩序（エントロピーの極小化）」という実装においてほぼ同一になるバグも説明できません。  
枝雀の分類を政治に適用するなら、「社会のエントロピーをどう管理するか」という設計思想の軸で整理できそうです。多次元の事象を1次元で議論しようとする強引さが、現代の対話における探索コストを無駄に跳ね上げている元凶かもしれません。

ワイ：  
まずは政治（=集団の意思決定）体制の主要な分類軸を列挙したい。  
・誰が決めるかの軸  
・何に関する意思を決めるかの軸  
・なぜ決めるかの軸  
・いつ決めるかの軸  
・どこで決めるかの軸  
・どのように決めるかの軸  
こんなものですかね？

Gemini:  
5W1Hのフレームワークで政治体制の設計変数を切り出していくアプローチは、非常に理にかなっています。伝統的な「右・左」が感情やアイデンティティに依存した「形容詞の分類」であるのに対し、これは「関数の引数」を定義するような構造的な分類ですね。  
■誰が決めるか（Actor）  
単一ノード（独裁） / 特定クラス（貴族・エリート） / 全ノード（直接民主制） / 代表ノード（間接民主制）  
■何を決めるか（Scope）  
資源配分（経済） / 行動規範（道徳・宗教） / 外部境界（外交・国防） / 意思決定ルールの変更（憲法）  
■なぜ決めるか（Objective）  
全体の生存（安全保障） / 効率の最大化（成長） / 効用の平準化（平等） / 個人の自由の保護  
■いつ決めるか（Trigger）  
定期的（選挙） / 異常検知時（緊急事態） / 随時（直接投票） / 過去の踏襲（慣習法）  
■どこで決めるか（Domain）  
中央サーバ（中央集権） / エッジ（地方自治） / 分散ネットワーク（連邦制・DAO）  
■どのように決めるか（Algorithm）  
多数決（過半数） / コンセンサス（全会一致） / 物理的衝突（闘争） / 非対称な強制  
現代の政治分類を最も混乱させているのは「何を決めるか（Scope）」と「どのように決めるか（Algorithm）」の混同ではないでしょうか。「民主主義（どのように）」はあくまでプロトコルですが、しばしば「自由主義的であるべき（何を決めるか）」という制約とセットで語られるため、「民主的な手続きによって、個人の自由を制限する決定を下す体制」というバグが発生します。  
このように「誰が・何を・どうやって」を独立した変数として定義すれば、従来のラベルでは表現不可能な新しい体制のプロトタイプも正確にマッピングできそうです。
