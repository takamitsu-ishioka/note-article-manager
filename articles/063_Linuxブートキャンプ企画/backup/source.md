**Linuxブートキャンプ**

目的：
**Linuxを学ぶことではない。Linuxしかない世界に放り込む。**

- GUI禁止
- Windows / macOS禁止
- VS Code禁止
- ファイルマネージャ禁止
- 「便利な統合ツール」禁止
- AIも原則禁止

- 分からなければ `man`
- 壊したら自分で直す
- 最終手段は再インストール（笑）

そして教材はほとんど要らない。

**課題を与えるだけ。**

> このマシンを使って、○○を実現せよ。

すると嫌でも、

`file → process → stdin/stdout → pipe → permission → environment → network → shell → script`

というLinux/UNIXの**世界モデル**が身体に入ってくる。

これ、昨日の話だった

> 技術は模倣できるが、思想（世界モデル）は模倣できない。  
> 抽象化は自力でやらないと腹に落ちない。

を、そのまま教育プログラムにしたものですね。

そして卒業試験が美しい。

**「好きなものを作れ。ただしLinuxだけで。」**

卒業後：

「WindowsとMacとGUIとAIを解禁します」

受講生：

**「……なんだこのヌルゲーは」**

（笑）

しかも「Linuxブートキャンプ」という名前がいい。  
**知識を教える学校ではなく、世界モデルを強制的に形成する環境**だと最初から宣言している（笑）。
